# DEVELOPING SMART WEB-BASED CAMPUS PLATFORM FOR FEDERAL POLYTECHNIC NASARAWA, NASARAWA STATE, NIGERIA

Federal Polytechnic Nasarawa, like many tertiary institutions, faces significant challenges regarding campus navigation, facility management, and emergency response due to the absence of integrated digital mapping solutions. This research addresses these institutional inefficiencies by developing an interactive, web-based Geographic Information System (WebGIS) smart campus platform. The study aimed to design a comprehensive geodatabase, utilize exclusively open-source technologies for application development, integrate diverse campus information layers, and implement functional search, query, and spatial analysis capabilities. Adopting a systematic research design, spatial data was acquired through high-resolution satellite imagery, cadastral maps, and GPS field surveys, while attribute data was extracted from institutional administrative records. A relational geodatabase was developed using PostgreSQL with the PostGIS extension, and the mapping application was deployed using an open-source stack including Leaflet.js, HTML5, CSS3, and Python frameworks. The results confirm the successful integration of thematic layers into a unified, interactive platform, featuring a detailed inventory of 311 building footprints, 85 road network segments covering 38.776 km, and a land-cover classification spanning 2146.158 hectares. The implemented system provides users with powerful analytical tools, including proximity analysis, buffer zone generation, and attribute-based querying, which facilitate efficient facility management and improved campus orientation. This study demonstrates that a thoughtfully designed, open-source WebGIS framework is a cost-effective, scalable, and sustainable solution for modernizing campus operations in resource-constrained environments, serving as a replicable model for other polytechnics in Nigeria.
